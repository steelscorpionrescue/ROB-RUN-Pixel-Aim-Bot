## Calibration by map

Keep three profiles, one per lighting group: day, dusk, interiors. Each profile has its own tolerance. HDR off is the easiest baseline.

## Install

Admin loader, ROB RUN, F8 toggles, INSERT for profiles.

## Troubleshooting

Wall shooting: tolerance high. Never fires: low, or HDR changed. Both: recalibrate.

Smallest detection surface of all builds here. Windows 10/11, Steam, EAC.
